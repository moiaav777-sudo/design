# Источники и лицензии

Реестр начат 11 октября 2026.

Раздел с композициями, переходами и историями слайдов удалён из проекта по решению владельца. Сторонние реализации из изученных источников не включались.

Проверка ранее добавленных библиотек в vendor, шрифтов и географического контура остаётся незавершённой. Сохраняйте уведомления правообладателей. Публичность репозитория не заменяет лицензию.

Для новых материалов фиксируйте источник, версию, правообладателя, лицензию кода и отдельно данных, способ использования и обязательные уведомления. Материалы без установленного разрешения не включайте.
