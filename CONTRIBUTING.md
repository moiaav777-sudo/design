# Участие в Design Visual Lab

Публичный каталог визуализаций для сайтов, аналитики и презентаций. Предложения приветствуются: сначала Issue с целью и демо или PR в отдельной ветке.

## Требования к вкладу
- Добавьте описание задачи, ID, превью, совместимость, зависимости и исходники; обновите каталог командой `node scripts/build-catalog.cjs`.
- Используйте только демонстрационные или обезличенные данные. Уберите реальные ФИО, контакты, токены, идентификаторы и скрытые метаданные. Не допускайте повторной идентификации по сочетаниям атрибутов.
- Уважайте авторские права, проверяйте лицензии зависимостей и приводите атрибуцию.
- Проверьте мобильную версию, клавиатуру, читаемость, `prefers-reduced-motion`, корректность ссылок и отсутствие ошибок в консоли.
- Для внешних PR запрещено запускать непроверенный код с секретами или токенами записи; публикация только после проверки и разрешённого merge.
- Не меняйте файлы на главной ветке напрямую. Разработка проводится через PR; maintainer проверяет результат.

## Как предложить новый пример
Откройте Issue: цель и аудитория, тип визуализации, ссылка на демо, исходники, лицензия, описание данных и ожидаемая польза.
