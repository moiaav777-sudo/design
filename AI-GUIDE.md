# Как собрать презентацию с помощью промпта

Основная ссылка: https://moiaav777-sudo.github.io/design/

## Для человека

1. На главной нажмите «Скопировать промпт» (полный текст) или «Короткий, для ИИ с интернетом».
2. Вставьте промпт в любую нейросеть (Claude, ChatGPT, Gemini, Cursor, GigaChat и т. п.).
3. В конце промпта замените три заглушки:
   - **Мой материал** — текст, тезисы, цифры, таблицы или старая презентация (можно приложить файл).
   - **Мой стиль** — словами, дизайн-токенами, ссылкой или файлом-примером, брендбуком. Если оставить пустым, будет нейтральная светлая тема. Неон не включается, пока вы сами его не попросите.
   - **Пожелания по приёмам** — необязательно, например «бюджет — водопадом».
4. Получите один HTML-файл. Откройте его в браузере: стрелки или свайп листают слайды, `F` — во весь экран, `Ctrl+P` — сохранить в PDF.

## Что делает промпт

Главное в нём — выбор приёма визуализации и динамики под смысл слайда, а не оформление:
каждая мысль материала сопоставляется с приёмом из каталога (сравнение, динамика, доли, цель, процесс, связи, прогноз и т. д.), динамика показывает порядок рассуждения, главное подсвечивается. Цифры берутся только из материала; если данных нет, ставится явная заглушка.

## Состав

| Файл | Назначение |
|---|---|
| `prompt-full.txt` | Полный самодостаточный промпт: правила, справочник из каталога и шаблон-образец |
| `prompt-short.txt` | Короткий промпт со ссылками, для ИИ с доступом в интернет |
| `deck-starter.html` | Шаблон-образец: движок слайдов, дизайн-токены, три темы (клавиша `T`), основные приёмы |
| `catalog.json` | Машиночитаемый каталог приёмов: смысл, взаимодействие, зависимости, исходник |
| `scripts/prompt-template.txt` | Исходный текст инструкции |

## Для разработчика

- После изменения каталога, шаблона `deck-starter.html` или `scripts/prompt-template.txt` пересоберите промпты:
  `node scripts/build-prompt.cjs` (проверяет, что все ID из таблицы «задача → приём» есть в каталоге).
- После изменения примеров пересоберите каталог: `node scripts/build-catalog.cjs`, затем промпты.
- Внешний вид шаблона держится только на токенах в `:root` и `[data-theme]`; новые приёмы добавляйте на токенах и с отключением анимации при `prefers-reduced-motion`.
- Не используйте реальные персональные данные в примерах. Данные в демонстрациях условные.
