## Скачать проект

Нажмите **Code → Download ZIP** на странице репозитория и распакуйте архив. Все библиотеки и шрифты включены в проект.

## Локальный запуск на своём компьютере

Если хотите редактировать и проверять галерею у себя, установите Python 3, откройте терминал в распакованной папке проекта и выполните:

```sh
python3 -m http.server 8765
```

После запуска сервера откройте [http://localhost:8765](http://localhost:8765) на том же компьютере. Этот адрес работает только пока локальный сервер запущен. Сборка и установка дополнительных пакетов не требуются.

## Файлы

- `index.html` — портал.
- `gallery.js` — поиск, фильтры и управление примерами.
- `demos.js`, `charts.js`, `stories.js`, `ideas.js` — примеры и сцены.
- `brand-portal.css`, `brand-demos.css` — оформление по брендбуку.
- `vendor/` — сторонние библиотеки; условия использования см. в их лицензиях и документации.

Данные демонстрационные.
