## Скачать проект

Нажмите **Code → Download ZIP** на странице репозитория и распакуйте архив. Все библиотеки и шрифты включены в проект.

## Локальный запуск на своём компьютере

Если хотите редактировать и проверять галерею у себя, установите Python 3, откройте терминал в распакованной папке проекта и выполните:

```sh
python3 -m http.server 8765
```

После запуска сервера откройте [http://localhost:8765](http://localhost:8765) на том же компьютере. Этот адрес работает только пока локальный сервер запущен. Сборка и установка дополнительных пакетов не требуются.

## Файлы

- `index.html` — главная; `gallery.html` — библиотека, где у каждого примера микрокарточка с живым превью; `catalog.html` — подбор по задачам и сравнение.
- `deck-starter.html` — шаблон-образец презентации (движок, дизайн-токены, три темы); `prompt-full.txt`, `prompt-short.txt` — промпты для нейросети, собираются `scripts/build-prompt.cjs`.
- `atlas-cards.js` — микрокарточки: ленивое живое превью примеров (не больше 10 живых iframe одновременно).
- `atlas-fx.js` — эффекты, общие для страниц: hero-сфера на canvas, живые мини-графики, печатающийся заголовок, счётчики, появление по скроллу, наклон карточек, магнитные кнопки, свечение за курсором. Всё тяжёлое работает только на экране и отключается при `prefers-reduced-motion`.
- `atlas-light.js` — главная: подбор по задаче, категории, бегущие ленты и числа из `catalog.json`. `gallery.js` — поиск, фильтры, крупный просмотр и исходный код.
- `demos.js`, `charts.js`, `stories.js`, `ideas.js` — примеры и сцены.
- `atlas-light.css` — дизайн-система портала (токены цвета, свечения, карточки, диалоги); имя осталось от прежней светлой темы, его проверяет CI. `catalog-v2.css`, `catalog-cinematic.css` — шапка, сравнение и карточка применимости на странице каталога.
- `brand-demos.css` — неоновая тема самих примеров (поверх `demo.css`); `scene-dark.css` — тёмная тема отдельных сцен. Превью сцен лежат в `previews/`.
- `vendor/` — сторонние библиотеки; условия использования см. в их лицензиях и документации.

Данные демонстрационные.

## Презентация за один промпт

Скопируйте промпт на [главной](https://moiaav777-sudo.github.io/design/#agents), вставьте в любую нейросеть, добавьте свой материал и стиль (описание, дизайн-токены, пример или брендбук) — и получите HTML-презентацию, где каждая мысль показана подходящим приёмом из каталога. Образец результата: [deck-starter.html](https://moiaav777-sudo.github.io/design/deck-starter.html). Подробности: [AI-GUIDE.md](AI-GUIDE.md).
