# Галерея интерактивов

92 живых примера анимации данных, графиков и интерактивных сцен на GSAP. Оформление по брендбуку: Golos Text, белый фон и фирменные синие оттенки.

[Открыть портал](https://gsap-motion-atlas-alexa.moiaav.chatgpt.site/)

## Запуск

Из папки проекта выполните:

```sh
python3 -m http.server 8765
```

Откройте http://localhost:8765. Сборка и установка пакетов не требуются. Библиотеки и шрифты находятся в проекте.

## Файлы

- `index.html` — портал.
- `gallery.js` — поиск, фильтры и управление примерами.
- `demos.js`, `charts.js`, `stories.js`, `ideas.js` — примеры и сцены.
- `brand-portal.css`, `brand-demos.css` — оформление по брендбуку.
- `vendor/` — сторонние библиотеки; условия использования см. в их лицензиях и документации.

Данные демонстрационные.
